MINORCA 2026 - PWA

Questa cartella e' pronta per essere pubblicata come sito statico HTTPS.
File principale: index.html

Dopo la pubblicazione:
- Android / Chrome: menu -> Installa app o Aggiungi a schermata Home.
- iPhone / Safari: Condividi -> Aggiungi alla schermata Home.
- Il pulsante posizione funziona solo su HTTPS (e dopo il consenso alla geolocalizzazione).

La mappa usa OpenStreetMap/Leaflet e richiede connessione per caricare le tessere cartografiche.
